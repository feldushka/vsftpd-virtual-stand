Отсутствие принудительной проверки целостности на транспортном уровне протокола SMBv2/v3 открывает возможность для проведения сетевых атак класса Man-in-the-Middle.
Если цифровое подписание пакетов сервером не переведено в разряд обязательных, атакующий может прозрачно модифицировать проходящие пакеты на лету.

В секции [global] файла конфигурации /etc/samba/smb.conf требование подписи пакетов отключено:
[global]
server signing = disabled

Сканирование режима безопасности сетевого шлюза
Для удаленной верификации уязвимого состояния конфигурации используется специализированный скрипт сетевого сканера nmap:
nmap --script smb2-security-mode -p 445 <IP_СЕРВЕРА_ЖЕРТВЫ>

В выводе сканера фиксируется флаг поддержки, не накладывающий жестких ограничений на целостность:
PORT    STATE SERVICE
445/tcp open  microsoft-ds

Host script results:
| smb2-security-mode: 
|   3:1:1: 
|_    Message signing enabled but not required
Статус Message signing enabled but not required означает, что сервер готов принимать неподписанный трафик от клиента, что делает инфраструктуру полностью уязвимой к MITM-модификации.
