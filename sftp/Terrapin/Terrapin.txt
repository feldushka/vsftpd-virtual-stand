Уязвимость CVE-2023-48795 (Terrapin) представляет собой фундаментальную атаку на логику построения префиксов сообщений в протоколе SSH. 
Находясь в позиции MITM, злоумышленник осуществляет манипуляцию порядковыми номерами пакетов на этапе согласования параметров соединения.
При использовании уязвимых режимов шифрования (потоковый шифр ChaCha20-Poly1305 или блочные шифры в режиме CBC-EtM), атака позволяет незаметно для клиента и сервера удалять пакеты расширений безопасности. 
Это приводит к принудительному ослаблению криптографических свойств сессии и отключению современных механизмов защиты от атак по сторонним каналам.

Использование версий OpenSSH, не поддерживающих расширение Strict Key Exchange, при одновременной активации уязвимых алгоритмов в конфигурации сервера /etc/ssh/sshd_config:
Ciphers chacha20-poly1305@openssh.com
MACs hmac-sha2-512-etm@openssh.com

Моделирование целевой криптографической среды 
Для проверки устойчивости парсера в конфигурационный файл сервера вносится контролируемый набор потенциально уязвимых шифров:
Ciphers chacha20-poly1305@openssh.com,aes128-ctr,aes256-ctr
MACs hmac-sha2-512-etm@openssh.com,hmac-sha2-256-etm@openssh.com

Запуск префиксного криптографического сканера
На стороне атакующего компилируется и запускается специализированная утилита анализа Terrapin-Scanner, имитирующая инъекцию префиксов в процесс рукопожатия:
git clone https://github.com/RUB-NDS/Terrapin-Scanner.git
cd Terrapin-Scanner && go build
./Terrapin-Scanner --connect <IP_ЖЕРТВЫ>:22
Результат и верификация защищенности 
В ходе выполнения аудита сканер считывает параметры сессии современной версии демона безопасности и фиксирует наличие встроенных контрмер:
Remote Banner: SSH-2.0-OpenSSH_9.6p1 Ubuntu-3ubuntu13.16

ChaCha20-Poly1305 support:   true
CBC-EtM support:             false
Strict key exchange support: true

The scanned peer supports Terrapin mitigations and can establish
connections that are NOT VULNERABLE to Terrapin.

Вывод работы: Тестирование подтверждает, что актуальные версии OpenSSH нативно нейтрализуют криптографическую уязвимость протокола Terrapin
